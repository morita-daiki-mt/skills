# レビュー対象の固定

`target.md` に対象リポジトリと仕様の参照先、比較元・HEAD・merge-base の SHA、差分の範囲、含める未追跡ファイルを記録する。PR の場合は固定 SHA のコードを読み、最終報告前にリモートの head が動いていないか照合する。変動を検出した場合は、旧版の指摘と新版を再確認した結果を区別する。

未コミット変更を含む場合は、レビュー開始・各フェーズ終了・最終報告前に、次の情報を同じ範囲で比較する。

- HEAD と index の状態。たとえば `git diff --cached --binary --no-ext-diff --no-textconv` のハッシュを比較する。
- 作業ツリーの追跡ファイルの差分。たとえば `git diff --binary --no-ext-diff --no-textconv` のハッシュを比較する。
- 対象の未追跡ファイルと、差分に含まれない関連コード・仕様のパスと内容のハッシュ。ファイルの追加・削除、シンボリックリンク先の変更も確認する。別のファイルを読む必要が出たら、読んだ時点の版とパスを記録する。
- 対象に適用される規約やレビューの根拠となる入力。無関係な変更も差分ハッシュに乗る場合は、変更されたパスを確認して影響を判断する。

内容が変わった場合は旧版を参照する合意を保持したまま、新版を対象に両者へ再確認する。内容を照合できなければ判定を保留する。実行記録は必要なパスとハッシュに絞り、無関係な未追跡ファイルや秘密情報を保存しない。
